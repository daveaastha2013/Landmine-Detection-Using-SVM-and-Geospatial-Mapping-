# Landmine-Detection-Using-SVM-and-Geospatial-Mapping-

### Overview
- This is an implementation of a Support Vector Machine (SVM) classifier to predict the presence of landmines based on sensor
data (metal detection intensity, ground density, GPS coordinates).
- For this particular code, we generate a random sensor data which can later be replaced by actual data.
- We visualise the detected landmines on a map created by folium
- The model accuracy, precision, f1 score and confusion matirx are calculated to judge its performance.

## How to use
- Clone the repository.
- Download all requirements.
- Run analyse_sensor_data.py

In order to use specific sensor data
- Edit the code
